# Citation checklist

Every reference the `[CITATIONS]` block of the output file and `<base>.bib` can contain, from the table in
`src/harness/mod_citations.f90` (generated by `scripts/make_citation_checklist.py`). Columns: **cited when** is the condition on the run that makes Direwolf print it; the reference as stored; its DOI (click to
open the publisher page). The Libxc version, its reference and the references of each selected functional are
not in this list: Libxc reports them itself at run time.
