# Contributing

Direwolf is developed solely by QuantaBricks. **External code
contributions (pull requests) are not accepted.**

This keeps copyright in a single hand, which is what lets the project be
offered both under the AGPL-3.0 (see [LICENSE](LICENSE)) and, separately,
under a commercial license for closed-source use. Merging outside patches
would compromise that.

## What is welcome

- **Bug reports** and **reproducible test cases** via the issue tracker.
- **Feature requests** and design discussion via issues.
- Questions about building, usage, or the input formats.

If you have a fix in mind, describe it in an issue. If it is adopted it
will be reimplemented independently.
